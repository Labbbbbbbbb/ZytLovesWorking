1. 将转换并验证得到的`kmodel`文件放置在K230`sd_card\example\kmodel`文件夹中
2. 运行以下代码
```python
from libs.PipeLine import PipeLine
from libs.YOLO import YOLO11
from libs.Utils import *
from media.display import *
import os,sys,gc
import ulab.numpy as np
import image
import utime
import machine

if __name__=="__main__":
    try:
        # 这里仅为示例，自定义场景请修改为您自己的模型路径、标签名称、模型输入大小
        kmodel_path="/sdcard/examples/kmodel/best.kmodel"
        labels = ["test"]
        model_input_size=[640,640] # 该参数必须与训练使用的imgsz参数保持一直

        # 添加显示模式，默认hdmi，可选hdmi/lcd/lt9611/st7701/hx8399,其中hdmi默认置为lt9611，分辨率1920*1080；lcd默认置为st7701，分辨率800*480
        display_mode="lcd"
        rgb888p_size=[1920,1080]
        confidence_threshold = 0.5
        nms_threshold=0.45
        # 初始化PipeLine
        pl=PipeLine(rgb888p_size=rgb888p_size,display_mode=display_mode,osd_layer_num=2)
        pl.create()
        display_size=pl.get_display_size()
        '''
        PipeLine(...) → 初始化一个图像采集 + 显示 + OSD 管理器。

		osd_layer_num=2 → 创建两个图层（显示文字、结果等）。

		pl.create() → 创建显示和摄像头资源。

		display_size = pl.get_display_size() → 获取屏幕尺寸，用于图像缩放和显示。

		PipeLine 统一管理摄像头和显示，方便后续 YOLO 推理直接拿图像。
        '''
        
        # 初始化YOLO11实例  task_type="detect" → YOLO 是检测任务，可选 "classify"。
        yolo=YOLO11(task_type="detect",mode="video",
					kmodel_path=kmodel_path,labels=labels,
					rgb888p_size=rgb888p_size,
					model_input_size=model_input_size,
					display_size=display_size,
					conf_thresh=confidence_threshold,
					nms_thresh=nms_threshold,
					max_boxes_num=50,debug_mode=0)
        yolo.config_preprocess()
        fps_img = image.Image(pl.display_size[0], pl.display_size[1], image.ARGB8888) #创建 FPS 显示图像
        last_time=utime.ticks_us()
        cur_time=utime.ticks_us()
        delta_time=(cur_time-last_time)/1000
        while True:
            os.exitpoint()
            cur_time=utime.ticks_us()
            delta_time=(cur_time-last_time)/1000
            last_time=cur_time
            
            #这里是为了在显示屏上实时显示 FPS 和温度信息。fps就是与显示屏大小相同的专门用于显示文字的透明图层
            fps_img.clear()
            fps_img.draw_string_advanced(0, 0, 32, f"{machine.temperature():.2f} C", color=(255, 0, 0))
            fps_img.draw_string_advanced(0, 32, 32, f"{delta_time:.2f} ms", color=(255, 0, 0))
            Display.show_image(fps_img, 0, 0, Display.LAYER_OSD2)  #把fps图层画在第二个osd层上
            # 逐帧推理
            img=pl.get_frame()
            res=yolo.run(img)
            yolo.draw_result(res,pl.osd_img)
            pl.show_image()
            gc.collect()
    except KeyboardInterrupt as e:
        print("用户停止: ", e)
    except BaseException as e:
        print(f"异常: {e}")
    finally:
        yolo.deinit()
        pl.destroy()

```



说明：

```
摄像头原图
       |
       v
   +-----------+   OSD1: YOLO框
   | OSD Layer1|
   +-----------+
       |
       v
   +-----------+   OSD2: FPS / 温度文字
   | OSD Layer2|
   +-----------+
       |
       v
屏幕显示 (pl.show_image)
显示时，OSD2 图层会覆盖在 OSD1 上（文字叠加在框上），再覆盖到摄像头原图上。
也就是说不管是OSD1还是OSD2，都是pipeline创建出来的用来绘制结果的图层，都不包括原图片本身，它们最后都得叠加到原图片上.
```

```
yolo.draw_result(res,pl.osd_img)

YOLO11 类的方法，用于把检测结果绘制到图像上。

参数：

res：YOLO 推理返回的检测结果
通常是列表/数组，每个元素包含：
检测框坐标 [x1, y1, x2, y2]
置信度 conf
类别 class_id

pl.osd_img：这是 PipeLine 的 OSD1 图层
图像类型一般是 ARGB8888
YOLO 框会绘制在这个图层，而不覆盖摄像头原图
```
